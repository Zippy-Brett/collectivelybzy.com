LEARN TO BEND THE RULES

Turn. Settle. Clear.

← / → Turn the entire grid 90°. Loose blocks and your active piece fall to the new bottom. Each turn locks your piece.
SPACE Hard-drop without turning. Fill a horizontal row to clear it. Keep the ceiling open.
ESC / P Pause or exit to title. Falling gets 15% faster every 3 cleared lines.

CONTROLLER D-pad / stick or LB / RB: turn.
A / Cross: drop or confirm. Start / Options: pause.
B / Circle: back or exit menu. Y / Triangle: sound.
Use the D-pad / stick to select any menu option.

✹ BOMBOn landing, clears a 3 × 3 area.
❄ FREEZEOn landing, turns lock for 4s. You can still drop.
